📄 The Specific Stub Files (What they do initially)
File	               Purpose
helpers.               php	Holds global functions. Auto‑loaded via composer.json.
OrderStatus.php	       Defines PENDING, BAKING, READY as native PHP Enums. Gives autocomplete in your IDE.
UserRole.php	       Defines ADMIN, STAFF, CUSTOMER. Used to restrict access.
ApiResponseTrait.php   Provides success() and error() methods so every API response looks identical (professional!).
ImageUploadTrait.php   Centralizes file upload logic. If you change storage from local to S3, you only change it here.
BaseRepository.php	   Extend this to avoid rewriting find(), create(), update() for every single model.
BaseService.php	       Extend this for common service logic (e.g., logging activity).
RoleMiddleware.php	    Checks if Auth::user()->role matches the allowed roles before letting them proceed.
